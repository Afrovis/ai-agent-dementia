Zones

Draw the bed zone, door zone, and bathroom path on a frame from the room, so perceive can tell where the person is relative to each one. Coordinates are saved normalised (0.0–1.0), so redrawing is not needed if the camera resolution changes later.

When zones overlap, the order that decides which one wins is fixed: bed, then door, then bathroom path, then “other” for anywhere else. Draw zones not to overlap where that matters — see perceive/zones.py for why the order is fixed.
