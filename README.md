# Night Companion

A local, embodied AI agent that helps a person with dementia get safely back to bed at night. It watches for wake-ups with a camera, opens a session with a goal, reorients the person in time and space through a calm screen face and voice, and alerts the family caregiver when needed.

Not a medical device. Not a substitute for supervision.
